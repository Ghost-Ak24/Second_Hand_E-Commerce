# CampusMarket Frontend
React + Vite + Tailwind CSS frontend for the Spring Boot marketplace.
Run:
npm install
npm run dev
Open http://localhost:5173
Backend default: http://localhost:8080/api
Copy .env.example to .env to change API URL.
Implemented: register/login/JWT, product CRUD, search/filter/pagination, categories, wishlist, purchase/order completion, reviews, responsive navigation and mobile menu.
Images currently use image URLs because the backend currently stores image URLs; Cloudinary can be added later.
